# 系統架構與技術文件

## 技術與執行環境

| 項目 | 實作 |
| --- | --- |
| 平臺 | Android，minSdk 24、compileSdk／targetSdk 35 |
| 語言與建置 | Kotlin 2.0.21、JDK 17、Gradle Wrapper 8.10.2、Android Gradle Plugin 8.7.3 |
| 使用者介面 | Jetpack Compose、Material 3（Compose BOM 2024.11.00） |
| 定位 | Google Play services Location 21.3.0，融合定位 |
| 地圖 | osmdroid 6.1.20、OpenStreetMap 圖磚 |
| 內建資料 | `app/src/main/assets/toilets.json`；以 Python 3.10+ 標準函式庫離線產生 |
| 外觀設定 | Android SharedPreferences（只儲存顯示模式、預設色編號、Hue 值） |

`app/build.gradle.kts` 設有 `debug`、`release` 與 `prerelease` Build Type。`prerelease` 的版本名稱是 `1.0.0-prerelease`，啟用 R8 壓縮及資源縮減，使用 Debug 簽章，輸出 `app/build/outputs/apk/prerelease/app-prerelease.apk`；這是測試發行 APK，不代表正式發布或正式簽章。

## 分層與資料流

```text
臺南市政府環境保護局 CSV 快照
  └─ tools/prepare_toilets.py → 驗證、整理名稱、合併場所 → app/src/main/assets/toilets.json
                                                                      │
手機 GPS → Google 融合定位 → MainActivity → ToiletRepository.load() ───┤
                                   │                                  ├─ 距離排序 → 最近 50 個場所 → 清單卡片
                                   └─ Appearance / SharedPreferences  └─ 全場所 → 視野篩選／聚合 → osmdroid 地圖
                                                                                                  │
使用者點「Google Maps 瀏覽」 ──────────────────────────────────────────────────────────────────────→ 外部地圖 App／瀏覽器
```

專案沒有自建伺服器；GPS 位置在裝置內用於距離與地圖顯示，不會上傳到本專案的後端。地圖圖磚及外部地圖連結由各自服務處理。

## 主要程式位置

| 路徑 | 職責 |
| --- | --- |
| `app/src/main/java/tw/toilet/nearby/MainActivity.kt` | 定位權限、活動生命週期、清單／地圖／卡片、Google Maps 外部連結 |
| `app/src/main/java/tw/toilet/nearby/ToiletRepository.kt` | 讀取 JSON；計算直線距離並取最近 50 筆 |
| `app/src/main/java/tw/toilet/nearby/MapMarkers.kt` | 投影目前視野的點、產生數字標記與地圖聚合結果 |
| `app/src/main/java/tw/toilet/nearby/ScreenClustering.kt` | 依畫面像素與鄰近格子歸類；測試位於 `app/src/test/` |
| `app/src/main/java/tw/toilet/nearby/Appearance.kt` | 系統／淺色／深色模式、主題色、設定頁與系統列樣式 |
| `tools/prepare_toilets.py` | CSV 檢查、名稱正規化、產生 JSON；測試位於 `tools/test_prepare_toilets.py` |

## 運作細節

1. `MainActivity` 在背景執行緒讀取 APK 內 JSON，切回主執行緒更新 Compose 狀態。讀取失敗會顯示錯誤畫面。
2. 啟動時請求精確／約略定位；先嘗試最近的快取位置，再要求目前位置，並在前景訂閱定位更新；活動停止時移除更新。已過期的快取位置不會作為初始位置。
   從清單點「地圖」頁籤會以已有的使用者位置和 18 級地圖置中，點廁所卡片則以 18 級移到該場所；地圖的「定位」按鈕另外要求一次高精度、不可使用快取的位置（最多等待約 15 秒）；成功後更新清單距離、置中地圖並設為 18 級，失敗時保留原畫面。
3. `ToiletRepository.nearby()` 使用 Android `Location.distanceBetween` 計算兩點間的**直線距離**，排序後取 50 筆；小於 1 公里顯示公尺，其餘顯示到小數第一位公里。路線長度並未計算。
4. 地圖在目前投影範圍內取所有場所；同座標先成組，再以螢幕上 **24 dp** 半徑比較新點與現有組的中心。聚合計算可隨移動或縮放改變，畫面更新延遲約 **120 ms**，避免每次手勢事件都重畫；數字代表場所數。
5. 不同座標的數字標記被點擊時，地圖以最多約 **19.5 級**逐步放大；同座標、或放大後仍重疊的場所透過底部清單選取。地圖標記及空白處點擊由 osmdroid 的 overlay 處理。
6. App 以 `geo:` URI 嘗試開啟 Google Maps；未安裝時使用 Google Maps 網頁搜尋 URI。地圖服務的使用條款與資料授權請見[授權與第三方資源](授權與第三方資源.md)。
