# 貢獻指南

歡迎以 GitHub Issue 回報 App 操作、地圖、資料或文件問題；若提供修正，請說明重現步驟、預期結果及實際結果。涉及公廁資料錯誤時，附上原始公廁編號與[資料集 7005](https://data.gov.tw/dataset/7005)對應資訊，避免只憑地圖標記位置猜測來源。

## 開發及檢查

1. 參照[系統架構與技術文件](系統架構與技術文件.md)與[系統設計文件](系統設計文件.md)，維持 Kotlin／Compose 和目前模組分工。
2. 修改資料整理邏輯時，更新 `tools/test_prepare_toilets.py`；修改畫面像素聚合邏輯時，更新 `app/src/test/java/tw/toilet/nearby/ScreenClusteringTest.kt`。
3. 提交前執行：

   ```powershell
   python -B -m unittest discover -s tools -p 'test_*.py'
   .\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
   ```

4. 資料集更新應先使用 `tools/prepare_toilets.py --check` 檢查，再產生新的 `toilets.json`；同步更新文件中的數量、版本與來源標示。不要加入 `local.properties`、金鑰或建置目錄。

若修改與授權或資料來源有關的內容，請核對根目錄的 [LICENSE](../LICENSE)、[NOTICE.md](../NOTICE.md) 及[授權與第三方資源](授權與第三方資源.md)。
