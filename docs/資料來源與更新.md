# 資料來源與更新

## 來源與授權

- 提供機關：**臺南市政府環境保護局**。
- 資料集：[臺南市公廁地址／政府資料開放平臺資料集 7005](https://data.gov.tw/dataset/7005)。
- 資料授權：[政府資料開放授權條款－第 1 版](https://data.gov.tw/license)。原始 CSV 與整理後 JSON 屬於依該資料集衍生的內容，**不是因為專案程式碼採 MIT 就改以 MIT 授權**；來源標示請見根目錄 [NOTICE.md](../NOTICE.md)。
- 目前原始快照：根目錄 `907f0805-d09d-41ea-80cd-563368c420f4.csv`（**4,449 筆**）；Android 資產 `app/src/main/assets/toilets.json`（**2,383 個場所**）。數量會隨來源更新而變化。

## 資料格式

轉檔工具讀取 UTF-8／UTF-8 BOM 的 CSV（使用 `csv.DictReader`，支援正常的引號與逗號欄位）。CSV 必須包含下表右側的欄位；來源中的 `Seq`、`筆畫序` 可存在，但 App 不使用。

| JSON 欄位 | CSV 來源與轉換 |
| --- | --- |
| `id` | `公廁編號`；同一場所多筆來源以第一筆編號為代表。 |
| `name` | `公廁名稱`；僅移除與 `公廁類型` 對應的尾字（「xx廁／xx廁所」），保留樓層及其他地點細節。 |
| `region` | `縣市`＋`鄉鎮名稱`＋`村里名稱`；非街道地址。 |
| `categories` | `公廁類型` 的不重複陣列；名稱尾字為「員工混合廁」時以此獨立標籤呈現。 |
| `latitude`、`longitude` | `緯度`、`經度`，轉為浮點數。 |

**合併條件**：緯度、經度、行政區域文字與整理後的完整場所名稱都相同才合併；不因同座標或共同短前綴就把不同商家／樓層合在一起。例如「奇美醫院樹林院區1F員工混合廁」會歸至「奇美醫院樹林院區1F」，並顯示「員工混合廁」標籤。轉檔保留資料出現順序，各類型標籤去重；原始 CSV 不被修改。

產出 JSON 為 UTF-8 陣列，以下為目前資料的其中一個元素：

```json
{
  "id": "D330000286",
  "name": "奇美醫院樹林院區1F",
  "region": "臺南市南區新昌里",
  "categories": ["女廁所", "男廁所", "員工混合廁", "無障礙廁所"],
  "latitude": 22.986491,
  "longitude": 120.19622
}
```

## 更新步驟

需求：Python **3.10+**（不需要額外套件）。在專案根目錄執行：

```powershell
python -B tools/prepare_toilets.py "新版資料.csv" --check
python -B tools/prepare_toilets.py "新版資料.csv"
python -B -m unittest discover -s tools -p 'test_*.py'
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

- `--check` 驗證與統計，但不寫入；不帶此旗標時預設更新 `app/src/main/assets/toilets.json`。需要檢查另一個位置時可使用 `--output 路徑`。
- 必要欄位缺失、欄位值空白、編號重複、座標非數字／超出範圍或零筆資料會使轉檔失敗；舊 JSON 保留。工具先寫同目錄暫存檔，再替換目標檔，以免留下半寫入的資產。
- 建置成功後，確認 APK 內的 `assets/toilets.json` 為本次版本，再更新根目錄 README、NOTICE 及本文件的**資料數量、來源資訊與授權標示**。App 不會自動從網站同步資料。

## 資料使用限制

此資料集目前不提供現場即時可用狀態或實際道路導航距離。資料版本、欄位與內容由原提供機關管理；後續版本若改變欄位名稱或含義，應先更新轉檔程式和測試，而不是直接覆寫內建 JSON。
